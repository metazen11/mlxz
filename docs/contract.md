# Project Contract

This page mirrors the operating contract in the root `CONTRACT.md` so the documentation site can link to the continual-improvement rules without leaving the docs tree.

The contract is the project-level loop:

- measure the engine
- fix the highest-leverage bottleneck
- run correctness and integration tests
- benchmark against `mlx-lm`
- keep only changes that improve the target workloads

See the root `CONTRACT.md` for the canonical version.
